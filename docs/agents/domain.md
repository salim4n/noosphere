# Domain docs

This repository is single-context. Before engineering work, read:

- `docs/context/current-state.md` for observed truth;
- `docs/context/architecture-spec.md` for the Agent Desk blueprint;
- `docs/context/decisions/` for source-of-truth and permission decisions;
- `docs/context/plans/active/` for the current implementation plan.

The root `AGENTS.md` remains the contribution and safety authority.
