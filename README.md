# Noosphere

A personal agent forge: deliberate planning, parallel execution, verifiable delivery.

## Status

Project initialization. No runtime has been deployed and no agent orchestration is implemented yet.

The initial architecture and V0 implementation backlog are being prepared in a separate pull request.

## Direction

- Human-reviewed architecture and tickets before execution.
- Existing coding-agent CLIs on a dedicated VPS.
- Herdr for persistent terminals and supervision.
- Separate Git worktrees, bounded concurrency, and evidence-based validation.
- No automatic merge, production access, or secrets in this repository.
